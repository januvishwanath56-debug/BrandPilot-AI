# Demo script and fictional brand knowledge (planning-only)

## LumaLeaf
A fictional organisation selling reusable 750 mL bottles. All facts in this file are made up for this demo; they do not describe a real commercial product.

### Approved facts
- `FACT-01` — LumaLeaf bottles contain **60% post-consumer recycled plastic**.
- `FACT-02` — LumaLeaf provides a **12-month limited manufacturing warranty**.
- `FACT-03` — The standard LumaLeaf bottle capacity is **750 mL**.

### Governance rules
- `POL-01` — Never describe the bottle as "100% plastic-free"; it contains plastic.
- `POL-02` — Avoid unverified absolute environmental claims, such as "guaranteed to save the planet".
- `POL-03` — Avoid unsubstantiated superlatives, e.g. "best in the world".
- `POL-04` — Use the exact brand style `LumaLeaf`, not `lumaleaf`.
- `POL-05` — Avoid vague CTA text like `click here` for accessibility reasons.
